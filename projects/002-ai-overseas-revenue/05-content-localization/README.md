# 05 内容本地化｜英文软件教程简中交付

## 可复用字幕工作台

**只有英文视频。** 选择视频，点击「识别英文并翻译」。第 01 项的 Faster Whisper 模型每 75 秒识别一段，两侧各保留最多 3 秒上下文。工作台加回各段在原视频中的起点，按重叠处的词和时间合并，再按停顿和句末组织成字幕。可看到逐段进度。Argos 把这些英文字幕翻成中文初稿。 [7 分 50 秒真人教程实测](RESULTS.md#真人长教程分段识别实测)

**已有英文 SRT。** 导入视频和 SRT。需要校时就点「估算时间偏差」，工作台用英文原声匹配字幕，在开头、中间、结尾给出回听点，并显示每处的原时间和建议时间。确认后点「一键应用校正」，起止时间一起平移，生成中文初稿前可撤销。直接生成会沿用 SRT 的原时间。两条路径共用审校界面，点字幕行可回放、改文字和起止时间，再导出 UTF-8 简中 SRT。 [打开工作台](http://127.0.0.1:43733/) · [CS50 整轨校正实测](RESULTS.md#导入官方-srt-后的整轨校正实测)

视频在浏览器播放。自动识别和整轨估算时，视频临时发送到本机服务提取音轨，请求结束后关闭临时文件。两项上限均为 10 分钟、512 MiB。直接翻译只提交字幕文本，支持最多 2,000 条非空字幕。匹配不足或三段偏差不一致时，工作台会提示逐条审校。字幕有一部分越过片头或片尾时，应用校正会收至视频边界。整条超出时暂停应用，保留原时间。工作台会提示重叠并拦截导出中的空字幕、无效时间和超出视频时长的结束时间。编辑内容留在当前页面，换片前可先导出。

在整个项目库内使用。所需 Python 包和模型只需准备一次。随后启动本地服务即可。

```powershell
python -m pip install -r requirements.txt
python -X utf8 -B server.py --prepare-model
python -X utf8 -B server.py --port 43733
```

自动识别读取第 01 项的 `.models/faster-whisper-base`，复用共享模型文件。新机器可按第 01 项说明准备模型。 [语音模型准备](../01-independent-website/README.md)

「载入仅视频样例」可用 18.523 秒的 Willow Calendar 演示试识别。「载入带 SRT 样例」复用 Cedar Notes 的英文视频和对应字幕。也可用文件选择器导入。 [仅视频样例](sample/willow/willow-calendar-reminder.mp4) · [带 SRT 样例视频](sample/cedar/cedar-notes-export.mp4) · [样例英文 SRT](sample/cedar/cedar-notes-export.en.srt)

## 要解决的问题与价值判断

一个卖在线软件的团队已有英文录屏，计划给中文用户发布教程。团队需要一个**中文用户看得懂、能按画面完成操作，负责人能按期发布**的版本。首轮服务聚焦 60–90 秒的单条教程，交付简中字幕、界面术语对照和播放器验收结果。最可能付钱的是已有定稿素材、有明确发布渠道和日期，又缺少中文审校人手的产品营销或客户教育团队。

**具体到一个操作。** 第 03 项自制演示在 00:29.250 至 00:33.570 提醒用户点 `Invite members`。审校把草稿里的「邀请人员」改成模拟委托方确定的「邀请成员」。交付时根据目标画面决定上屏写法。画面显示英文时，可以写「点击看板顶部的 Invite members（邀请成员）」，用户能找到按钮。画面使用简中界面时，采用实际显示的中文按钮名。遇到旧视频上的按钮已改名、移位或缺失，要记下时间点让客户确认，必要时提供同版素材。 [已有样例与审校记录](../03-digital-products/RESULTS.md)

| 买家场景 | 能买到的结果 | 初步价值 |
| --- | --- | --- |
| 近期要上线中文功能页、帮助文档或培训，已有匹配版本的英文录屏 | 一次对术语、画面、字幕时间轴和播放器导入负责的交付 | 优先验证。发布节点明确，少一次返工就能体现价值 |
| 产品经常更新，同一负责人反复维护一批帮助视频 | 稳定沿用客户术语，按产品版本更新字幕和核验步骤 | 有复购可能，先观察第二条真实视频是否交给同一人处理 |
| 通用视频只想批量生成低成本中文字幕 | 自动转写和初译草稿 | 付费空间偏弱。现有编辑器已提供英中自动字幕翻译，先了解客户用现有工具做到哪一步。 [CapCut 视频翻译](https://www.capcut.com/tools/video-translator) |

一个历史委托要求交付英译简中 SRT。另一个业务方在为英语用户改编中文软件教程时，要求复现操作、核对过期界面并更新字幕。这些委托说明文件交付和操作复现都曾被买家列为要求。这个细分方向的买家规模、试价接受度和复购率仍待验证。 [英译简中字幕委托](https://www.freelancer.cn/projects/translation/need-english-simplified-chinese-31801310) · [MagicCanvas 教程本地化委托](https://www.freelancer.co.uk/projects/video-editing/tutorial-editor-english-localization)

**阶段判断。** 值得先验证一单固定范围的服务。第 03 项的工作台是给制作方自行处理字幕的工具。第 05 项由服务方用这套流程交付客户能发布的文件，客户按条付费。可以先从现有样例剪出一段带界面操作的演示来讲清验收标准。正式试单看客户是否提供真实定稿、愿意付费，是否采用文件发布。确认有需求后，再以每单从接收素材到客户确认的净工时判断经营价值。

## 首个买家和付款理由

选择已经有英文产品演示、也有简中产品页或明确中文发布计划的小型 SaaS 团队。实际买家可能是创始人、市场负责人或负责产品发布的人。优先找近期要更新视频的人，需求强度可以用明确的素材、发布渠道和日期判断。

试单卖的是可直接上传的简体中文字幕。遇到 “workspace” 这样的词，先查客户中文版界面到底写什么，整条视频沿用同一表达。按钮名、操作步骤和产品承诺要与当前画面一致，客户发布时就能少做一次逐句返工。

## 把一单做成可验收的交付

| 项目 | 试单范围 | 验收方式 |
| --- | --- | --- |
| 客户输入 | 一条 60–90 秒的英文演示，视频或清晰音轨、目标平台和已有术语 | 开始前确认视频版本、文案基准和需要保持原样的术语 |
| 中文字幕 | 一份 UTF-8 简中 SRT | 用目标播放器完整看一遍，字幕与操作画面对齐，切换时能顺畅读完 |
| 术语表 | 标明产品名、功能名和按钮名 | 与客户页面和界面用语一致，待确认项有明确标记 |
| 修改 | 一次集中反馈，修订后交付最终文件 | 区分翻译、计时和素材版本变更，记录修改时间 |

如果目标是 YouTube，先按其支持的基本 SRT 格式测试导入。YouTube 支持为视频添加语言并上传字幕，基础 SRT 以纯 UTF-8 格式提供。客户确认后自行发布。 [YouTube 添加字幕](https://support.google.com/youtube/answer/2734796?hl=en) · [YouTube 支持的字幕格式](https://support.google.com/youtube/answer/2734698?hl=en)

## 第一份样片怎么做

从第 03 项的自制演示选约 20 秒，复用英文素材和已有字幕。放入同一画面的 AI 初译与人工审校稿，标明编辑了哪个按钮词、怎样分句、在哪一秒核对。请一位中文读者跟着成品完成一次关键操作。这个检查能先验证画面和字幕搭配的效果，付款与实际发布再由真实试单验证。

收到素材后，先确认发布时间和字幕平台，再做转写。AI 初译可以减少起稿时间。人工逐句确认专名、按钮、数字和否定句，按画面拆分和校时，导入播放器通看后交付。对画面上看不清或语音含混的词集中问一次。

## 七天试单

1. **第 1 天**。准备 20 秒样例、术语样例和范围说明。用 49 美元、素材齐备后 48 小时内交首稿、含一次集中修改作为首轮测试设置。报价和交期以真实耗时和客户反馈校准。
2. **第 2–4 天**。找 15 家有英文演示且有中文需求信号的团队。优先使用对方公开的业务联络入口。每条消息说明观察到的产品页面和演示素材，附样例和报价，问近期有无可试的一条视频。
3. **第 5–7 天**。拿到试单就做完一个交付，记录调查、沟通、转写、翻译、校时、导入检查和修改的实际用时。让客户标出原本还需要自己改的地方，核对中文观众能否跟做关键操作，再记录确认、发布和下一条视频的安排。

可直接改写的英文开场。  
“Hi [name], I saw that [product] has a Simplified Chinese page and an English demo for [feature]. If you’re preparing a Chinese release, I can deliver upload-ready Simplified Chinese subtitles for one 60–90 second clip for $49, including a UI glossary and one revision. Would that fit a release you’re working on?”

## 收益、质量和复购

假设第一单收 49 美元，触达分摊 30 分钟，制作 60 分钟，沟通、交付和修改 30 分钟，总计 2 小时。扣工具和支付费用前为每小时 24.50 美元。如果每单都因素材改版多花 1 小时，降到约 16.33 美元每小时。素材版本、时长和修改范围会直接影响有效时薪。

- **先验证愿付**。15 家里能拿到 1 个付费试单，就有一条可继续观察的信号。实际发布或得到明确的发布排期，才验证了成品用途。
- **再验证复购**。客户有连续更新的视频，且术语和画面模板能沿用，可以试按月交三条。先用前两次实际交付记录核算时间。
- **遇到阻力先定位**。少回复，检查客户是否近期真的要发简中内容。愿意聊但无预算，确认谁决定发布。客户付费却不发布，逐项回看交付是否与播放器、术语或发布素材版本匹配。

**第一轮最值得追踪的事件**是第一笔付款到第一次实际发布之间发生了什么。用这段记录改报价、范围或交付流程。
