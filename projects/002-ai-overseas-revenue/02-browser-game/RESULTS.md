# 网页小游戏试玩记录

这里保留两款原型的浏览器实测、记录口径和后续真人试玩方法。表中的流程结果来自浏览器验证，真人结果待收集。 [阶段总结](README.md)

## Cargo Switch 浏览器实测

2026 年 11 月 22 日，使用 Chromium 跑完了首轮原型。测试先用桌面键盘和点击操作，再切到 390 × 844 的窄屏验证布局和滑动分拣。

| 实际操作 | 观察到的结果 |
| --- | --- |
| 点 Start shift，用左方向键分拣首个圆形包裹 | 得到 100 分，连击为 1。 |
| 点击与下一个包裹匹配的货位 | 本件获得 125 分，总分 225，连击为 2。 |
| 故意分到错误货位 | 总分降到 175，连击清零，显示该包裹对应的货位。 |
| 在剩余 44 秒时暂停，稍后回来查看 | 仍显示 44 秒，点 Resume 后继续计时。 |
| 窄屏上向右拖动菱形包裹 | 正确入库，总分 275。三个货位各约 106 像素宽，页面没有横向滚动。此轮验证使用桌面浏览器的窄屏视口和指针输入。 |
| 等倒计时到 0 秒，再点 Play again | 结算为 275 分、4 件中分对 3 件。重开回到 45 秒、0 分、0 连击，首包重新为圆形。浏览器未记录 JavaScript 错误。 |

## 接下来的真人试验

当前证据支持玩法技术上可跑完一局并重开。真人首次理解、真实手机上的手势，以及玩家有没有兴趣主动开第二局仍待验证。

### 试玩面板的记录口径

| 指标 | 当前记录方式 |
| --- | --- |
| 首次分对用时 | 从首次开局到第一次有效分对，累计前台回合内经过的时间。暂停与结算等待排除，逐人记录并显示中位数。 |
| 首局完成 | 首局正常跑到结算就记一人，提前结束记录保留为未完成。 |
| 主动重开 | 玩家操作结算页的 Play again 就记一人，多次重开仍计一人。观察者不提示重开。 |
| 累计活跃满 60 秒 | 跨局累计回合内的活跃区间。每次有效分拣开启最多 5 秒的计时，相邻区间合并。长时间无操作、暂停、结算和后台时间排除，达到 60 秒记一人。 |

面板按匿名参与记录汇总。每位新玩家点一次 Record next player，结束后点 End recording。刷新保留已保存的数据，页面回到练习模式。CSV 还包含开局状态和每位玩家的累计活跃毫秒数。

记录功能在隔离浏览器页完成自动验证。一次首局记录了首次分对和首局完成。重开后持续操作，累计达到 60 秒，重开与达标人数各增加一人。刷新后记录仍在，CSV 可下载。时钟回归另验证了挂机排除、59,999/60,000 毫秒边界和暂停。运行 `node check-playtest.cjs` 可重现时钟回归。以上均为程序验证数据。

## 儿童识图原型实测

最初的猫狗鸭原型使用九张真实照片、三条中文问题和三段叫声录音。浏览器跑完一轮 6 题。首题故意选错仍停在原题，之后六次答对均播放对应动物叫声。三种动物各出现两次，两次使用的照片和左右位置都不同。第六题显示完成并可重开，重开回到第 1 题，浏览器未报告 JavaScript 错误。

### 自动进题与试玩记录

面向学龄前低龄儿童，开局后只需要听和点图。选对有大勾和动物叫声，叫声结束后自动继续。选错留在当前题并重播提示。六题答完停在找到的动物照片上，孩子可以自己点「再来一轮」。每种动物第二次为答案时用此前还没出现过的照片，并换到另一侧。连续最多两题答案在同一侧。

| 观察项 | 记录口径 |
| --- | --- |
| 首次选对用时 | 从首题显示开始，到第一次点中正确照片。包含先前点错和重听题目的时间。 |
| 自己玩完六题 | 游戏记录答对几题。达到 6/6 后，由观察者标注整轮是否有口头提示或代点。 |
| 换图后还能否认出 | 分别记录小猫、小狗、小鸭换图题的第一下点选。答错再答对仍保留首选错，没做到的题单独标记。观察者另标注这些点选是否有协助。 |
| 主动再玩 | 游戏记录结算页的重开点击，由观察者标注孩子是否在无人提醒时自己点。 |

真人试玩用无广告版本。大人先开启记录，再把设备交给孩子。第六题后留给孩子自己决定，观察结束再标注是否有协助。普通试玩不写记录，记录只保存在当前浏览器，可导出 CSV。

浏览器跑完六题，验证了六次正确反馈及其叫声、自动进题、换图换边、结算和手动重开。故意选错一题换图题后补对，记录显示首轮 6/6、换图首选 2/3。重开前记录为「未重开」，点击后才计入重开人数。三项观察可手动标注，刷新后记录保留，CSV 下载成功。另跑一轮普通试玩确认不会生成记录。以上是程序验证，真人结果待收集。 [儿童识图游戏](animals.html) · [照片与声音来源](animals-assets/CREDITS.html)

### 听叫声模式实测

新版首页加入「听叫声找动物」，与「听名字找动物」共用猫、狗、鸭的九张照片和三段真实叫声。新增三条独立中文报名字的音频。两种玩法各六题，答完可以原玩法再来一轮，也可以试另一种玩法。

| 实际操作 | 观察到的结果 |
| --- | --- |
| 听叫声模式跑完六题 | 六题都从正确的叫声开始，选对后播放对应动物名字并自动继续。三种动物再出现时都换了照片和左右位置。 |
| 第一题按「再听叫声」，第四题先选错再选对 | 重听和选错都播放同一题的叫声。第四题留在原处，最后换图首选记为 2/3，首轮完成记为 6/6。 |
| 从听叫声的结算切到听名字 | 首轮仍标「听叫声」，下一轮标「听名字」。原玩法跑完六题，仍是听中文题目，答对播叫声，再来一轮回到第 1 题。 |
| 导出 CSV 并刷新 | CSV 附有首轮玩法和下一轮玩法，刷新保留记录。旧记录按当时可用的「听名字」显示。 |

试玩面板仍记录首次选对时间、首轮完成、换图首选和开启下一轮。有无成人协助仍由现场观察者标注。上述数据来自浏览器流程测试，孩子的玩法偏好待真人验证。

### 农场主题实测

首页增加「农场」主题，包含鸡、羊、牛，每种准备了三张真实照片、一段实录叫声和两条中文语音。猫狗鸭与农场都可以选「听名字找动物」或「听叫声找动物」，每轮仍是六题。结算页可以再来一轮、换玩法或换主题。素材保存在项目里，试玩无广告。 [照片与声音来源](animals-assets/CREDITS.html)

| 实际操作 | 观察到的结果 |
| --- | --- |
| 农场「听叫声」跑完六题，第四题故意选错 | 选错留在原题并重播叫声。选对播放对应动物名字，随后自动进入下一题。三种动物第二次出现都换了照片和左右位置。首轮 6/6，换图首选 2/3。 |
| 农场「听名字」跑完六题 | 每题播放中文问题，答对播放对应叫声，自动到六题结算。结算点「试试听叫声」，农场保留并回到第 1 题。 |
| 从农场结算换主题再开一轮 | 记录首轮是「农场 / 听叫声」，下一轮是「猫狗鸭 / 听名字」。回到题面时使用猫狗鸭的照片和语音。 |
| 刷新与导出 CSV | 刷新保留首轮和下一轮的主题、玩法。CSV 分别列出它们，换图结果按首轮所属动物填写。没有主题字段的旧记录可按「猫狗鸭」查看。 |

以上为浏览器操作验证。真人试玩继续记录首次选对时间、首轮完成、换图首选和开启下一轮，有无成人协助由现场观察者标注。
