# 网页小游戏研究汇总与扩展

## 两个原型各自验证什么

| 维度 | Cargo Switch 货运分拣 | 《动物在哪里？》 |
| --- | --- | --- |
| 对象与核心操作 | 喜欢短局挑战的玩家。45 秒内点选或滑动，把包裹送到形状相同的货位。 | 学龄前低龄孩子。任选猫狗鸭或农场主题，听动物名字或叫声，从两张大照片里点选，一轮六题。 |
| 一局内的反馈 | 分对得分，连击带来额外奖励。分错扣分并重置连击。 | 选对会高亮并播放相应的名字或叫声，随后自动继续。选错可以重听并再选。 |
| 再玩一轮的理由 | 可以少错几次、提高连击或刷新分数。 | 可以看到不同照片、再听喜欢的动物叫声，也可能想找新的动物。 |
| 优先观察 | 是否能自己分对第一件，结算后会不会为了提高分数重开，重开后是否持续操作。 | 是否能独立完成，换一张没见过的照片时第一次点哪张，结束后是否自己点再来一轮。 |
| 商业假设 | 如果短局能持续复玩，可测试平台分发和结算后的广告对重开的影响。 | 如果孩子愿意在不同日期回来，可向家长测试农场、海洋等主题内容的需求和付费意愿。 |

两款都已通过浏览器流程和本地记录验证，包括重开、记录保留和 CSV 导出。独立完成、真人复玩、回访和收入都待验证。动物的换图数据衡量当轮二选一的识别表现。若要判断孩子有没有学会并记住，需要另做隔天的新照片测试。 [两款的实测与记录口径](RESULTS.md)

## 先跑同一版真人试玩

1. **每款先观察约 5 位目标玩家。** 货运分拣优先用真手机，观察第一次点击或滑动是否顺利。动物识图由家长先开记录、调好音量，再把设备交给孩子。都用当前无广告版本，保留打不开、中途停下和需要提示的情况。
2. **记录行为，再问继续或停下的原因。** 两款都看开局、首个正确操作、首轮完成和重开。Cargo Switch 另看累计活跃 60 秒，动物识图另看各动物换图后的首次点选和大人协助情况。汇总用各自的「已开局、完成、重开」逐层报告；动物识图另报「确认独立」和「确认主动」。两款首次正确用时的起点和计时方式各有定义，分别呈现。
3. **用具体卡点决定下一次改动。** 听完题却不知道点哪里，先改提示和触控。会玩但第一轮结束就停，先尝试多一个想继续的理由。每次改一个主要变量，用同样的观察方式再测一小轮，记录版本、设备和协助情况。小样本用于找问题并排优先级。

## 后续按需要扩展

两款先保留当前无广告版本。动物识图已完成自动进题、听叫声玩法和农场主题。后续遇到具体试玩现象，再选对应的一项验证。

| 试玩观察 | 可以试的扩展 |
| --- | --- |
| 孩子听完题仍常需要大人指示怎么点 | 先调整语音提示、两张图的大小或点选反馈，再看能否独立完成。 |
| 孩子玩完会主动再听喜欢的叫声 | 做一个点照片就能听叫声的图鉴，看孩子会不会自己打开。 |
| 孩子能独立完成并会主动换主题 | 加一组新动物，沿用六题和两图选一，观察发现新动物能否带来复玩。若孩子想尝试不同任务，可单独试「动物回家」分类关。 |
| 分拣玩家会为分数重开，玩几轮后觉得局内太像 | 试带处理顺序选择的加急件。 |
| 分拣玩家隔天还会回来挑战分数 | 再试每天固定一套出件顺序，保留本机最好成绩。 |

孩子试玩时记录先选哪种主题和玩法，以及六题后是再玩、换主题、换玩法还是停下。两种玩法的音频线索长度不同，首次选对用时按首轮主题和玩法分别查看。英语语音和家长付费入口等出现对应需求后再评估。 [农场主题实测](RESULTS.md#农场主题实测)

### 货运加急件暂列备选

货运分拣和三消都能用连续做对的即时反馈带来手感。典型三消里，先消哪里会改变后续棋盘。现有货运分拣每次只判断一个包裹的去向，复玩主要靠熟练后做得更快、更准。给当前包裹加一个小倒计时和额外分，主要会改变节奏。

若真人试玩发现玩家已经愿意为破纪录重开，但重复几轮后觉得局面太相似，可以试同时出现普通件和快过期的加急件。先处理普通件有机会保住连击，抢加急件能拿额外分。保留现有版做对照，观察玩家会不会换一种处理顺序、结算后是否更愿意重开。点击速度可作为节奏指标，主动重开和继续操作更贴近这次想验证的复玩价值。

## Cargo Switch 原始研究

现阶段值得用小样本试玩验证这个玩法。浏览器原型已跑通开局、分拣、结算和重开，商业潜力取决于真人是否愿意多玩、平台能带来多少有效会话，以及结算后的广告是否打断复玩。

### 核心玩法与复玩假设

每局 45 秒，玩家辨认包裹形状并把它送进对应货位。第一件分对得 100 分，连击加分最多到每件 200 分。分错扣 50 分且连击清零。结算显示成绩，玩家可以立刻重开，争取少错一次或打破刚才的分数。

当前的复玩动力是速度和正确率的取舍。玩家能看到错在哪里，也知道下次怎么多拿分。三个货位固定，包裹会等玩家操作，掌握规则后每局的决策变化较少。复玩假设是玩家会主动争取更高分，并在第二局继续分拣。通过行为和结束后的回答判断这条假设。

### 真人试玩怎么做

首批用当前无广告版本观察 5 位没见过玩法的玩家。观察者先开记录，再把准备画面交给玩家，让对方玩到自己想停。记录是否独立开局、首件分对花多久、是否完成首局、是否主动点重开、累计玩到 60 秒的人数。最后再问停下或继续的原因。

| 观察 | 后续决策 |
| --- | --- |
| 能开局，首个包裹仍经常分错 | 优先检查指引、货位标识和手机上的操作。 |
| 顺利结算，主动重开的人少 | 看玩家是否觉得已经玩够。同一玩法容易被看透时，先试一个局内挑战变化，再复测。 |
| 主动重开，第二局很快停下 | 看他们是否在尝试提高分数，以及第二局重复感从哪里开始。 |
| 主动重开后继续玩，玩家能说出下一局的目标 | 扩大试玩并查看真实分发后的平均游玩时长与次日留存。 |

初轮修复最大卡点后，可用 10 位新玩家做第二轮，至少 8 位独立开局、4 位主动重开作为项目继续投入的初筛线。这是内部观察门槛。CrazyGames 会关注开局后至少游玩 1 分钟的比例，实际平台数据以其统计为准。对 45 秒一局的原型，本地实验同时观察玩家是否进入第二局并继续操作。 [CrazyGames 转化指标](https://docs.crazygames.com/resources/basic-launch-metrics/#3-conversion)

### 变现要验证的假设

先积累无广告的复玩数据。若复玩达标，可以尝试平台分发看真实流量。CrazyGames 的 Basic Launch 能看真实游玩与留存，入选 Full Launch 并接入 SDK 后，可以测量实际计费展示、净收入，以及结算后插播对重开的影响。 [发布规则](https://docs.crazygames.com/requirements/intro/) · [广告放置指南](https://docs.crazygames.com/resources/ad-monetization-guide/)

用一组假设估量收入。每月 10,000 次游戏会话乘以每次平均 0.7 次计费展示，再乘以每千次展示净收入 4 美元，约得 28 美元。接入真正的分发与广告后，用计费展示和净收入替换假设。

当前最先要回答的问题是，有没有玩家因为想提高分数而主动重开并继续玩。 [真人试玩流程与记录](RESULTS.md)
