# 海堤街景

一段可在桌面浏览器步行和试驾的原创海滨街景。可沿街探索约 130 米，从试驾车起步可向前开约 120 米，街尾有拓宽的回车区。海侧步道比道路高 24 厘米，沿街设有坡道。

## 场景总案

把约 130 米的街区作为一个可独立体验的整体。玩家第一眼知道街道临海，走一小段就能找到车，开到分岔时能看懂观景台在哪，停好车能走到栏杆或长椅边，再沿支路汇回主街。也可以一直步行，或走主街直行到回车区。街区的可玩性来自走、开、停、看的切换和选择。

### 空间分区

表中距离是从玩家初始位置沿主街方向量的里程，支路节点按投影位置标注。

| 区域 | 位置 | 作用 | 该区必须交代清楚的事 |
| --- | --- | --- | --- |
| 街口与试驾车 | 约 0–15 米 | 建立建筑、车辆和人的尺度，让玩家选步行或上车 | 能辨认试驾车及车门所在侧，能从安全位置绕到车边 |
| 临街店铺与海堤步道 | 约 15–35 米起，步道沿主街续接 | 给街道生活背景，让玩家走得通、看得到海 | 店门、路缘、缓坡和栏杆各有用途，街具留出净通道 |
| 支路分岔 | 约 36 米 | 提供朝观景台驶去和沿主街直行两种选择 | 车辆到分岔前就能看见方向牌和线形，步行过渡有可读的边界 |
| 停车带与观景台 | 约 65–75 米 | 让驾驶自然转为停留和步行 | 入口能斜进，停车点允许开门；下车后能到栏杆和长椅，回头能找到车 |
| 汇流与街尾回车区 | 约 112 米汇流，115–134 米回车 | 把支路接回主街，给主街一个可识别的收尾 | 汇入方向和路缘可读；玩家能减速、回正或倒车调头，海岸和山体连续 |

### 场景约束

| 层面 | 制作规则 |
| --- | --- |
| 地形与比例 | 以米为单位，维持现有两三层街屋、24 厘米高差和约 1.65 米行人眼高。路线和标高先定，再布设施。关键步行通道按约 1.2 米连续净宽校核，在长椅、车门和转角处用人物与车模实测。 |
| 车与人的空间 | 先划分可行车面、停车带、走行带、车门扫掠区和观景停留点。地面、可走范围和碰撞边界对齐。停车可以从斜进和倒车两个方向完成；若必须穿过车道，行人集中在一个可辨识的交会点过街。 |
| 材质与光线 | 沿用 Sidmouth 实拍的阴天漫射光与低饱和色调，统一远山、水面与地平雾。沥青、石路缘、灰泥、板岩、金属各用一致的纹理尺度；磨损放在门槛、轮迹、岸边等有使用原因的位置。人物、车轮和街具都要有可信的接触阴影。 |
| 素材与人物 | 按区域复用灯杆、长椅、栏杆、建筑开间等组件；用位置、朝向和使用痕迹做变化。人物按“从哪来、去哪、为何停、如何离开”设计。走停转身要有重心过渡，脚掌贴合坡面，停留留出玩家操作空间。 |
| 玩法、镜头与声音 | 核心体验为自由步行、试驾与海边停留。路线靠路形、标线和地标引导，界面提示用于靠近后的操作和碰撞反馈。跟车镜头随转向平顺过渡；脚步、车门、发动机和轮胎声随接触或状态变化，海浪提供低音量的环境底声。 |

### 补充顺序与验收

1. **先补路线闭环。** 对照全图检查分岔处人车如何交会，以及停车后开门、走向长椅和返回车边的通道。现有散步行人经过支路与停车带边缘，把这条路线作为检查人车关系的样例。优先化解行人动线与车位、车门的重叠。
2. **再定各区的生活内容。** 按入口、店前、步道、观景台、街尾分配用途与素材密度。每项新内容说明它服务哪个节点、玩家何时看见、要做什么，以及占用的地面或视线。只有对应实际缺口时，才进入制作清单。
3. **整段验收后再扩展。** 从街口走到车边，试驾进入停车带，下车走到栏杆并坐下，再上车汇回主街、到街尾调头。另沿步道走一遍，检查分岔和停车带能否看懂、贴边或倒车会否误拦。用步行近景与驾驶视角检查比例和接缝，并确认场景声音随状态变化。

后续交给 AI 的单次任务应带上对应区域、玩家正在做的事、可用素材、尺寸与碰撞约束、验收路线。位置、地面和人车空间有冲突时，先修总图，再安排模型或动画。

## 本地启动

在项目目录执行以下命令。使用 Node.js 22.12 或以上版本。

```powershell
npm ci
npm run dev -- --port 5194
```

打开终端显示的本地地址。运行 `npm run build` 可生成静态构建。

## 操作

- 步行时用 `WASD` 或方向键移动，拖动画面环视，`C` 切换步行视角。
- 走到蓝灰色车的右前门旁按 `E` 上车。车门关闭后即可驾驶。用 `W` 加速，`A` 和 `D` 转向，`S` 减速或倒车，空格刹车。停车后按 `E` 下车，右侧需要留出开门空间。
- 沿主街前行，看到「海堤观景台」提示后跟着导向线靠右。中段可沿渐宽段驶入观景停车位，停稳后按 `E` 下车。走到靠街尾的长椅前，按 `F` 坐下看海，再按一次起身。沿支路导向线继续行驶会从另一端接回主街。
- 走到港务办公室门旁，按 `G` 查看海湾旧照。照片取自观景台，朝岬角可看到同一处低礁和航标。
- 走到观景台栏杆内侧的望远镜旁，按 `T` 使用。拖动画面转向，滚轮或 `+`、`−` 调整倍率，按 `Esc` 回到步行视角。
- `R` 返回起点并重置试驾车。
- 「观察机位」可看港务办公室、观景台海景、街道全景、车辆近景和海堤，也可重播观景台行人的来回路线。
- 点击顶部的光线名称，可在「薄云午后」与「冷灰阴天」之间切换。
- 「自动走一遍」从初始停车位置重播步行路线。按移动键或拖动可接管。
- 首次移动或点击后播放场景声音。左下角的声音按钮可切换静音。
- 「录制步行」从起点录制同一条约 20 秒的路线，使用浏览器支持的视频格式保存。

## 声音素材

音频已剪辑、调整电平并压缩为 Ogg Vorbis。车门和脚步按动作接触点播放，发动机循环随车速和油门变化，海浪由四段实录交叠循环。

轮胎滚动和刹车摩擦使用为这段沥青街道制作的循环音效。滚动声跟随实际车速和方向变化，刹车声按制动减速度起落，两者在接近静止时淡出。
